## Scraping Note
The site loads data via JS from `/assets/index-BbopfDyB.js`. The actual schedule data is NOT in the initial HTML — it's fetched client-side. To extract full schedules (departure times per line per direction), you'd need to:
1. Run the JS and intercept network requests
2. Or use a headless browser (Playwright/Puppeteer) with network interception
3. Or reverse-engineer the API endpoint from the bundled JS

The station/route list above is extracted from the filter dropdowns (which ARE server-rendered).
