# Louage Station Field Research Toolkit

## What You Need to Document at Each Station

### Station Profile
For each louage station, record:

| Field | Description | Example |
|-------|-------------|---------|
| Station name | Local name + French/Arabic | Bab Saadoun / باب سعدون |
| Location | GPS coordinates | 36.8096, 10.1617 |
| Address | Street/avenue | Avenue Habib Bourguiba |
| Governorate | Region | Tunis |
| Station type | Hub vs terminus | Main hub |
| Operating hours | First/last departure | 04:00 - 22:00 |
| Facilities | Waiting area, shop, WC | Yes/No |
| Contact | Phone number if posted | +216 71 XXX XXX |

### Route Data
For EACH route from this station:

| Field | Description | Example |
|-------|-------------|---------|
| Destination | City/region name | Sousse |
| Departure pattern | Fixed times or "when fill" | When full (every 15-30 min) |
| Fare (TND) | Current price | 12.500 |
| Duration | Approx travel time | 2h 30min |
| Frequency | Peak/off-peak | Every 30 min peak, hourly off-peak |
| Vehicle type | Mercedes Sprinter, HiAce, etc. | Mercedes Sprinter |
| Capacity | Typical passenger count | 14-15 passengers |
| Notes | Extra info | Via highway, stops at Sidi Bou Said |

### Research Protocol

**Preparation**:
- Print maps of the area
- Bring pen + notebook (phone battery may die)
- Have a working phone camera for photos
- Wear casual clothes (not obviously a researcher)
- Visit weekday AND weekend (different patterns)

**At the Station**:
1. Note the station name and GPS (Google Maps pin works)
2. Photograph any posted timetable/signage
3. Approach a driver or station attendant — say "I'm building an app for Tunisian transport, can you help me document routes?"
4. Ask about 5-10 most popular destinations
5. Note which platforms/areas serve which destinations
6. Take photos (discreetly if needed)

**Ethics**:
- Don't photograph people without permission
- Be respectful of workers' time
- Don't disrupt operations
- A small tip (2-5 TND) is appreciated if someone spends significant time helping

## Crowdsourcing Strategy (Post-Launch)

### In-App Contribution Flow
1. User taps "Add a Route" or "Report Incorrect Info"
2. Fill: Origin → Destination → Fare → Duration
3. Submit → goes to moderation queue
4. After 3 independent confirmations, route becomes visible
5. Contributor earns points/badge

### Gamification
- "Route Pioneer" badge for first contributor per station
- "Fact Checker" badge for verifying existing routes
- "Photographer" badge for station photos
- Leaderboard per governorate

### Data Quality
- Flag routes that differ from existing data by >30% fare
- Auto-reject routes with missing required fields
- Manual review for all submissions (until trust established)
