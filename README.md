# BLEDI.TN — Tunisia Public Transport Routing

A Tunisia public-transport routing project: a FastAPI backend, a local
multi-modal Dijkstra router, and a Leaflet frontend. Seed data covers 232
lines and 1,711 stations across Tunisia.

## What exists

**Single API** — `src/backend/app/main.py` is the one FastAPI entry point.
It loads the seed at startup, serves stations/lines/route/geocode, and proxies
OSRM (driving) + Nominatim (geocoding) through the backend with TTL caching.
The old skeleton and the broken importer are archived in `archive/`.

**Local router** — `src/backend/app/routing.py` implements a physical-cost
Dijkstra over the transit graph (stations = nodes, line segments = edges).
Walk 4.5 km/h, per-mode transit speeds (bus ~22 km/h, train/metro ~80 km/h,
RFR/tram ~28-70 km/h), half-headway wait, 3-minute transfer penalty, metered
taxi (0.600 DT base + 0.520 DT/km). No external cost metric.

**Frontend** — `frontend/index.html` is the canonical Leaflet UI. It calls the
backend via `/api/v1/*`, geocodes through the backend (no browser User-Agent),
and renders results with safe DOM (no `innerHTML` on tainted data). The older
self-contained `frontend/bledi-map.html` is kept in `frontend/` for reference
and is also shipped inside `bledi.tn-review.zip` as a handoff artifact; see
`docs/frontend-notes.md`.

**Seed** — `data/seed_all_tunisia_routes.json` (original, untouched).
`data/seed_all_tunisia_routes.tagged.json` is an additive tagged copy with
`source` + `license_status` on every station and line, generated by
`scripts/tag_provenance.py`. The original is never overwritten.

## Run it

```bash
# Install deps
python -m pip install -r requirements.txt

# Optional: OSRM for driving/taxi geometry (car profile)
docker pull osrm/osrm-backend
# docker run ... (see docs/quick-start.md)

# Start the API
uvicorn src.backend.app.main:app --host 127.0.0.1 --port 8000

# Frontend
open http://localhost:8000          # serves frontend/index.html
# or open frontend/index.html directly from disk (it calls /api/v1/*)
```

Environment variables:

- `OSRM_URL` — OSRM endpoint (default `http://localhost:5000/route/v1/driving`).
- `OSRM_TIMEOUT` — OSRM request timeout in seconds (default 10).
- `ALLOWED_ORIGINS` — comma-separated CORS origins (default localhost only).
- `ENABLE_TUNISMAPPER_PROXY` — set to `1`/`true`/`yes` to re-enable the
  Tunismapper itinerary proxy (disabled by default, returns 410).

## Data sources and licensing status

Most of the routing data is derived from **Tunismapper**. The terms of that
source have not been verified for redistribution. For that reason this
repository does **not** yet claim a license for the dataset.

See `docs/provenance.md` for the full audit:
- Lines: 227 tunismapper + 4 transtu PDF + 1 tunismapper URL
- Stations: 1,315 tunismapper + 266 official-public (by mode) + 130 unknown
- The `/api/v1/itinerary` Tunismapper proxy is disabled by default

`LICENSE.TODO` records that the license is undecided. No MIT or other license
is claimed for the dataset.
