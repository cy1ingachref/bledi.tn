## 3. Geolocation audit (bbox lat 30.2–37.6, lon 7.3–11.7; land-polygon water test)

- **Out of bbox: 0** (both files). Every coordinate with values lies inside the Tunisia bbox.
- **Missing coords: 8 in seed, 7 in transport_map_corrected** — all 8 are `quarantined: true` with documented reasons (Lake Ichkeul water bodies, a Tunis point labelled Ain Drahem, one user-reported bad point). They are **correctly nulled** — serving them would put stations in the sea. Full list in `data/phase1_missing_coords.csv`.
- **In water (land-polygon test): 14** in both files (same set). All are bus stops, 12 in the Kerkennah/Arway cluster (lon ~10.88–11.21) plus Ain Drahem (Tunis point) and Port Sidi Daoued extends past the Cap Bon coast. ⚠️ **Caveat:** GSHHG L1 land rings under-resolve small islands (Kerkennah), so some of the 14 may be genuine island land points flagged as sea. **Verify against OSM before quarantining** — do not mass-quarantine from this list.
- **Previous 772-flagged `water_stations.json` is disproven as ground truth.** Its rule (`lat > 37.3 and lon > 9.8`, etc.) flags Bizerte city itself. The land-polygon result (14) supersedes it. The 772 figure must not be cited.
- **Commune >30 km check: cannot be run from repo data.** Only `station_corrections.json` (5 entries, evidence-backed) uses it; no commune-centroid dataset exists in the repo. Listed as Phase 2 gap — do not claim the check was done.
- Duplicates/conflicts: 83 entries in `station_name_mapping.json` (multi-source coord disagreements, authority-ranked). `station_reference.json` (11,801) vs seed (7,452) overlap is partial by design — reference is a superset of sources, not a deduped master.

## 4. Trilingual names (`data/phase1_names.json`) — no invented names

- Reference coverage: `name_ar` field on 1,307 stations but **only 106 contain actual Arabic script** (the rest duplicate the Latin string, e.g. `name_ar: "13 Aout"`). Raw `name` has Arabic script on 1,801 stations. `name_en` on ~1,631.
- Mappings found for transport_map_corrected stations (7,502): **EN-only 7,400 · EN+AR 82 · EN+AR+FR 14 · EN+FR 6** (total with any AR/FR: 102). Every non-null `name_ar`/`name_fr` carries `source` provenance (`station_reference_name_match` or `station_reference_proximity_<m>m`); everything else is null, **not guessed**.
- Real examples: `MONCEF BEY → المنصف باي`, `BAB SAADOUN → باب سعدون`, `Hammamet → الحمامات`, `Station Louage Gabès → محطة النقل بقابس / Gabès Louage Station`.
- **BizerteConnect backlog:** all 131 lines have no stops and no coords (API has no stops endpoint). They are in `data/phase1_missing_coords.csv` (139 rows total with the 8 quarantined stations) as `line_no_stops_no_coords` — geocodable by endpoint names via Overpass/Nominatim in Phase 2. This, not the 8 quarantined stations, is the real geocoding workload.

## 5. Transport icons — created in `apps/web/static/icons/`

`bus.svg`, `train.svg`, `metro.svg`, `louage.svg`, `taxi.svg`, `walk.svg` — 24×24 stroke icons, stroke colours match `MODE_COLORS`, legible at 14–24 px. Simple geometric glyphs (front bus / train car / metro car / shared-minibus / taxi with roof sign / walking figure). **MapView.svelte was NOT modified** (hard constraint); usage snippet for Phase 2:

```js
// MapView.svelte — replace dot() for stations with:
const MODE_ICON = { bus:'bus.svg', metro:'metro.svg', train:'train.svg', rail:'train.svg',
  louage:'louage.svg', taxi:'taxi.svg', unknown:'bus.svg' };
function stationIcon(mode, color) {
  return L.divIcon({ className: 'station-marker',
    iconSize: [24,24], iconAnchor: [12,12],
    html: `<img src="/icons/${MODE_ICON[mode] ?? 'bus.svg'}" alt="" width="24" height="24" style="display:block">` });
}
// usage: L.marker([s.lat, s.lon], { icon: stationIcon(s.mode) })
```
